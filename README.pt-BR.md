# Meu Primeiro Portfólio

Este repositório representa um dos primeiros passos da minha trajetória na área de desenvolvimento.

Foi meu **primeiro projeto publicado no GitHub**, meu primeiro contato mais prático com commits, versionamento de código e organização de um projeto em um repositório.

O projeto consiste em um portfólio pessoal simples desenvolvido em HTML, criado com o objetivo de reunir informações sobre minha formação, conhecimentos e primeiros projetos na área de tecnologia.

## Sobre este projeto

Este portfólio foi desenvolvido no início da minha jornada de aprendizado.

Desde então, meus conhecimentos, projetos e experiências evoluíram bastante, por isso este repositório não representa necessariamente meu nível técnico atual.

Decidi mantê-lo disponível justamente como um registro da minha evolução como desenvolvedor.

## Tecnologias utilizadas

* HTML
* Git
* GitHub

## O que aprendi com este projeto

Além da construção da página, este projeto marcou meu primeiro contato com conceitos importantes como:

* Criação de repositórios no GitHub
* Commits
* Versionamento de código
* Organização inicial de projetos
* Estruturação de páginas HTML
* Publicação de projetos pessoais

## Evolução

Este projeto faz parte do início da minha trajetória.

Projetos mais recentes presentes no meu GitHub demonstram melhor os conhecimentos e habilidades que desenvolvi posteriormente.
