# My First Portfolio

This repository represents one of the first steps in my journey into software development.

It was my **first project published on GitHub**, as well as my first hands-on experience with commits, version control, and organizing a project inside a repository.

The project consists of a simple personal portfolio built with HTML, created to showcase information about my education, skills, and some of my first projects in technology.

## About This Project

This portfolio was developed at the beginning of my learning journey.

Since then, my knowledge, projects, and professional experience have evolved significantly, so this repository does not necessarily represent my current technical level.

I decided to keep it available as a record of my growth and evolution as a developer.

## Technologies Used

* HTML
* Git
* GitHub

## What I Learned

Besides building the webpage itself, this project marked my first experience with important concepts such as:

* Creating repositories on GitHub
* Making commits
* Version control
* Basic project organization
* Structuring HTML pages
* Publishing personal projects
